# 指导老师初稿指导日志

## 第一次指导

时间：2026年4月下旬  
地点：线上/线下指导  
指导内容：

1. 老师对论文初稿的整体结构进行了检查，认为目前已经具备“问题背景、模型方法、实验结果、系统展示”四个基本部分，但章节之间的逻辑衔接还不够紧密。
2. 老师建议进一步明确论文的研究对象与应用场景，强调本课题是基于离线交通时序数据的碰撞风险预测原型系统，不宜表述为实时生产级平台。
3. 老师指出模型部分的文字描述偏工程化，建议在正文中补充动态特征演化、空间注意力机制和后处理策略的作用解释，减少直接堆公式的写法。
4. 老师要求统一图表命名、编号和引用格式，尤其是实验结果表、消融实验表和前端展示截图要在正文中有明确引用位置。

整改意见：

- 调整论文整体结构，使引言、方法、实验、系统展示之间的层次更清晰。
- 补充研究动机和创新点说明，突出动态演化与空间建模的结合。
- 统一全文术语，避免同一概念出现多个名称。
- 补充答辩展示所需的图表索引和结果说明。

## 第二次指导

时间：2026年5月上旬  
地点：线上/线下指导  
指导内容：

1. 老师对修改后的初稿进行了复查，认为论文主线已经更清楚，能够基本反映项目的数据处理、模型设计、实验验证和可视化展示流程。
2. 老师建议进一步收敛正文表述，把复杂模型描述改写成更适合答辩表达的语言，突出“为什么这样设计”而不是单纯介绍模块名称。
3. 老师指出实验结果部分要重点说明 AUC-PR、F1 score 和 Recall 的含义，强调交通碰撞预测属于类别不平衡任务，不能只看 Accuracy。
4. 老师建议补充论文附录或答辩材料索引，包括指导日志、图表索引、答辩讲稿和演示兜底方案，便于后续检查和展示。

整改意见：

- 进一步精简论文中的重复描述，增强章节之间的递进关系。
- 补充实验指标解释，突出模型在召回能力和整体排序能力上的表现。
- 完善答辩材料目录，确保论文、图表、代码和演示文档相互对应。
- 对页面展示、目录和页码格式进行最终检查，保证正式提交版整洁统一。
