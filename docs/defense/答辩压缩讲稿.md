# 答辩压缩讲稿

## 8 分钟版

各位老师好，我的毕业设计题目是《基于 Attention-LSTM 的交通碰撞风险预测与可解释分析系统》。本项目主要围绕城市交通碰撞风险预警问题展开，目标是根据历史交通时序数据、事故标签和空间邻接关系，预测不同城市区域在未来时间片中的碰撞风险，并通过前端可视化系统进行展示和解释。

首先介绍研究背景。随着城市交通规模扩大，交通碰撞和交通拥堵问题越来越突出。交通碰撞风险并不是孤立产生的，它通常受到时间变化、道路结构、区域功能和历史事故模式等多种因素共同影响。对于交通安全预警来说，最重要的不是单纯追求整体准确率，而是尽量提前发现高风险区域，减少漏报。因此，本项目更关注模型对真实风险样本的识别能力，尤其是 Recall 和 AUC-PR 等指标。

数据方面，本文使用 NYC 和 Chicago 两个城市数据集。NYC 数据集包含 13,128 个时间片、64 个区域和 116 维特征，共 840,192 个区域-时间样本，正样本比例为 22.53%。Chicago 数据集包含 8,784 个时间片、27 个区域和 116 维特征，共 237,168 个样本，正样本比例为 13.38%。除交通时序数据和事故标签外，系统还使用了区域坐标映射，以及道路、POI、历史记录等空间邻接关系，用于辅助建模和前端解释。

模型方面，本文采用 Attention-LSTM 结构。LSTM 用于捕捉历史交通状态中的时间依赖关系，Attention 机制用于突出关键时间片和关键特征，使模型能够更关注对风险预测贡献较大的信息。模型最终输出每个区域在目标时间片上的风险概率。为了提高输出稳定性，系统还引入了平滑门和流式后处理机制，用于减少相邻时间片预测结果的剧烈波动，使结果更符合交通风险连续变化的特点。

实验方面，本文将 Myplan 模型与 GSNet、STG2Seq、ConvLSTM、LSTM、LightGBM、XGBoost、ARIMA、HA 等模型进行对比，评价指标包括 AUC-PR、AUC-ROC、F1、Accuracy 和 Recall。在 NYC 数据集上，本文模型的 AUC-PR 为 0.6955，AUC-ROC 为 0.8786，F1 为 0.6443，Recall 为 0.8265。在 Chicago 数据集上，AUC-PR 为 0.5617，AUC-ROC 为 0.8290，F1 为 0.4730，Recall 为 0.7055。可以看出，本文模型在两个城市数据集上都具有较好的高风险样本识别能力。

为了验证关键模块的作用，本文还进行了消融实验。结果显示，在 NYC 数据集上，完整模型的 Recall 为 0.8265，高于去除平滑门、去除流式后处理以及同时去除两者的配置；在 Chicago 数据集上，完整模型 Recall 为 0.7055，也高于其他消融配置。这说明平滑门和流式后处理能够提升模型对真实风险样本的识别能力，并增强预测输出的稳定性。

系统实现方面，本文构建了一个前端可视化大屏。由于原始 `.npy` 文件较大，浏览器不适合直接加载全量数据，因此后端将模型预测结果、真实标签校验、实验指标和空间拓扑关系导出为前端 JSON 文件。前端默认加载 NYC 和 Chicago 的代表性样本，其中 NYC 展示 13 个时间帧、64 个区域和 832 条区域-时间记录；Chicago 展示 13 个时间帧、27 个区域和 351 条记录。页面支持城市切换、时间轴播放、风险热力图、TP/FP/FN 标签校验、模型指标对比和局部空间邻接解释。

需要说明的是，当前系统定位为离线预测与可视化原型，不是实时生产级交通平台。前端展示的是后端导出的代表性样本，而不是直接加载全量时序数据。部分区域描述和展示文案用于增强可读性。后续可以进一步接入实时交通流、真实 GIS 边界、天气、施工和大型活动等数据，使系统扩展为更完整的在线交通风险预警平台。

总结来说，本项目完成了从数据构建、模型训练、实验评估到前端可视化展示的完整流程。实验结果表明，Attention-LSTM 结合平滑和后处理机制能够较好地识别交通碰撞高风险样本；前端系统进一步将风险概率、真实标签校验和空间拓扑解释可视化，为交通风险预警和结果解释提供了一个可运行的原型系统。我的汇报结束，谢谢各位老师。

消融实验表明，完整模型在两个数据集上的 Recall 均高于去除平滑门或流式后处理后的版本，说明这两个模块对提升召回率和稳定输出有帮助。
