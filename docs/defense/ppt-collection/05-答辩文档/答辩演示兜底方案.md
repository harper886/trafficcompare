本文档用于答辩现场演示兜底。目标是在网络不可用、浏览器加载异常、端口冲突或前端 JSON 加载失败时，仍然能够完整说明项目功能、模型流程和实验结果。

4. 展示模型指标对比，说明 Myplan 与基线模型的差异。
5. 展示拓扑或解释区域，说明模型使用了空间邻接关系。

## 3. 2 分钟演示讲稿

这个系统主要展示交通碰撞风险预测模型的输出结果。项目使用 NYC 和 Chicago 两个城市数据集，每个城市被划分为多个交通区域，模型根据最近 5 个时间片的交通状态、事故标签和空间邻接关系，预测每个区域的碰撞风险概率。

系统前端不是实时线上平台，而是离线原型展示。后端训练和推理脚本会把模型输出、真实标签、指标和拓扑关系导出为 JSON 文件，前端再读取这些 JSON 进行可视化。

页面中最核心的是风险热力图。颜色越明显，表示该区域当前时刻的风险概率越高。通过时间轴可以观察风险随时间变化的过程。系统还会对预测结果和真实标签进行对比，例如 TP 表示模型正确识别出的风险区域，FP 表示误报，FN 表示漏报。

模型部分，本文的主模型是 Myplan。它融合了动态特征演化、多分支空间注意力和 ConvLSTM。动态演化用于刻画交通状态随时间变化的过程；空间注意力用于学习道路、POI 和事故记录三类邻接关系下的区域影响；ConvLSTM 用于进一步建模时空特征并输出风险概率。

实验结果中，Myplan 在 NYC 和 Chicago 两个数据集上都取得了较好的 AUC-PR、AUC-ROC、F1 和 Recall 表现。特别是 Recall 指标在交通安全任务中比较重要，因为漏报高风险区域的代价通常比误报更高。

## 4. 30 秒极简讲稿

本系统是一个交通碰撞风险预测与可视化原型。模型根据历史交通状态、事故标签和空间邻接关系，预测不同区域的碰撞风险概率。前端展示的是由本地数据和模型结果导出的代表性样本，不是实时线上平台。项目的核心方法是动态特征演化、多源空间注意力和 ConvLSTM 时序建模，最终通过风险热力图、标签校验和模型指标对结果进行展示。

## 5. 现场常见问题兜底回答

### 页面打不开怎么办？

回答：

> 这个页面需要通过本地 HTTP 服务访问，不能直接双击 HTML 文件。如果现场端口或浏览器环境有问题，我会使用已经准备好的前端截图继续说明系统功能。

### 如果 JSON 加载失败怎么办？

回答：

> 前端优先读取 `results/` 目录下导出的 JSON 文件。如果 JSON 加载失败，页面会使用内置演示数据兜底。正式结果和指标已经整理在 `论文表格汇总.md` 和 `最终指标汇总与来源说明.md` 中。

### 这个是不是实时系统？

回答：

> 不是。当前系统是基于离线数据和模型推理结果的原型系统。它验证了从风险预测到可视化展示的完整流程，但还没有接入实时交通流、实时事故接口和生产级地图服务。

### 前端展示的数据真实吗？

回答：

> 前端展示的是从本地真实数据和模型输出中导出的代表性样本。为了保证浏览器性能，页面没有直接加载完整 `.npy` 大文件，而是加载导出的 JSON 文件。

### 如果老师要求看指标来源？

回答：

> 指标来源链路已经整理在 `最终指标汇总与来源说明.md`。原始实验表在 `p1结果展示.md`，前端指标 JSON 由 `export_frontend_metrics.py` 导出，论文整理表在 `论文表格汇总.md`。
