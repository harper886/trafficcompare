02 · 研究问题

传统模型的不足之处

1. 忽略动态演化交互

仅关注静态特征（如 POI、历史流量），忽略事件间的动态演化交互。

2. 数据不平衡

未有效处理数据不平衡，难以捕捉稀有异常事件的内在模式。

3. 空间依赖建模单一

不包括多视角（功能相似、碰撞历史、交通状况）的网格交互。

4. 动态特征过平滑

特征更新时易出现「过平滑」，导致正常与异常事件的特征差异被掩盖。

核心命题 → 如何同时捕捉时间依赖和空间关联，在不平衡数据中找到真正的高风险样本？

03 · 模型方法

核心架构：五大模块串联

01
数据预处理与滑动窗口加载 116 维交通特征 + 事故标签 + 三类邻接矩阵，滑动窗口构建 5 步时序样本。
02
动态特征演化论文提出的 update-decay 机制，有事故时更新、无事故时衰减，逐时间步更新动态状态。
03
多源空间注意力 × 2动态和静态特征各用一套独立的空间注意力。每套含功能相似 / 道路连通 / 历史碰撞三个分支，加权融合。
04
卷积长短时记忆 时空融合动态 + 静态特征拼接后输入 1×1 卷积LSTM，同时捕捉时间依赖和空间关联。
05
全连接输出 + Focal LossSigmoid 输出每个区域的风险概率。Focal Loss 解决类别不平衡，动态损失防止特征退化。

04 · 我的改进

平滑门 + 流式后处理：让预警更稳定

改进一 · 自适应平滑门 [模型内部]

传感器采到：11, 13, 9, 13, 15（有噪声）
真实情况：11, 13, 11, 13, 15（更平滑）
变化剧烈时门关紧 → 过滤噪声，让动态特征稳定可靠。

改进二 · 流式后处理 [输出端]

朴素决策（单阈值 0.70）：0.5 0.6 0.72 0.68 0.71 0.69 0.73 0.67 0.66 0.65 → 反复跳 3 次
滞回决策（开启 0.70 / 保持 0.65）：首次触发后维持，直到 < 0.65 才解除 → 只报 1 次，稳定不抖。
牺牲一点性能，但更面向实际应用。
