02 · PROBLEM

城市交通碰撞：为什么需要新的方法？

时间 × 空间 ≠ 独立问题

早晚高峰风险骤升，相邻区域存在风险传播。传统模型把区域当独立样本——丢失空间上下文。

Accuracy 是最坏的指标

事故是少数事件，正样本仅占 13%–22%。模型全判"安全"，准确率能到 78%——但召回率为零。

输出需要稳定

风险预测在阈值附近频繁跳变——"危险"↔"安全"↔"危险"——预警系统完全不可用。

核心命题 → 如何同时捕捉时间依赖和空间关联，在不平衡数据中找到真正的高风险样本？

03 · METHOD

三大模块：Evolution → MultiAttention → ConvLSTM

01
Evolution — 时序演化过去 5 个时间片逐步更新动态特征。自定义 update-decay 机制学习交通状态随时间的变化规律。
02
MultiAttention — 空间学习三类空间图：道路连通 / POI 功能 / 历史碰撞关联。各一个独立 Attention 分支，传播 6 轮。
03
ConvLSTM — 时空融合动态 × 静态特征联合编码 → 1×1 ConvLSTM → 每个区域的风险概率。

04 · MY CONTRIBUTION

平滑门 + 流式后处理：让预警更稳定

改进一 · 自适应平滑门 [模型内部]

动态特征变化剧烈 → 可能是噪声。平滑门让模型自己决定——信新特征还是保留旧特征——而不是直接覆盖。

改进二 · 流式后处理 [输出端]

双阈值滞回：开启阈值 ≠ 保持阈值。进入预警需高风险，退出需更低——中间 0.05 的滞回区间防抖动。类似施密特触发器。
