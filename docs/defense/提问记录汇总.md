## 八、重点问题详细答案

### Q1: 数据集详细介绍

NYC 和 Chicago 两个城市的交通数据。NYC 是 13128 个时间片 × 64 个区域 × 116 维特征，总共约 84 万条样本。Chicago 是 8784 × 27 × 116，约 23.7 万条。每个样本就是一个区域在一个时间点上的交通状态 + 事故标签（0 或 1）。正样本比例分别是 22.5% 和 13.4%，是典型的类别不平衡数据。每条样本有 116 维特征，数据已经标准化过，没有缺失值。另外还有三类邻接矩阵——道路连通、POI 功能相似、历史碰撞关联——用来描述区域之间的空间关系。

### Q2: 整个实验流程

五个阶段：数据准备（加载 npy 数据、滑动窗口构造时间序列样本、加载邻接矩阵）→ 模型构建（MYPLAN 包含 Evolution + MultiAttention × 2 + ConvLSTM + Dense）→ 训练与评估（Focal Loss + dy_loss，12 个对比模型 + 消融实验）→ 结果导出（推理 + 抽取 13 帧代表性样本 → JSON）→ 前端展示（dashboard_fixed.html 读取 JSON 展示热力图和指标）。

### Q3: 平滑门的作用

模型内部的动态特征每次更新时，会先生成一个"候选新特征"，然后平滑门根据新旧特征之间的变化量（delta）输出一个比例。变化大 → 门关紧，多保留旧特征，挡住可能的噪声。变化小 → 门打开，正常接收更新。两个参数 logit 和 scale 是可训练的，模型自己学会了什么时候保守、什么时候开放。消融实验证明去掉平滑门后 NYC Recall 从 0.83 降到 0.80。

### Q4: 流式后处理的作用

模型输出端分两步处理：第一步指数平滑（α=0.8），把原始概率序列的毛刺磨平。第二步双阈值滞回——触发预警要用一个较高的阈值，解除预警要用一个较低的阈值，中间 0.05 的缓冲区防止概率在临界值附近反复横跳。类似电路里的施密特触发器。消融实验证明去掉后处理后 NYC Recall 从 0.83 降到 0.74。

### Q5: 自适应平滑门具体设计

两个可训练参数：smooth_gate_logit（初始 -0.5，sigmoid(-0.5)≈0.38，默认倾向接受新信息）和 smooth_scale（初始 0.5，控制对变化量的敏感度）。核心公式是 smooth_gate = sigmoid(logit + scale × delta)，新特征 = smooth_gate × 旧 + (1-gate) × 候选。两个参数通过反向传播训练。

### Q6: 流式后处理具体设计

两步：指数平滑 smooth[t] = 0.8 × smooth[t-1] + 0.2 × pred[t] 磨平毛刺，然后双阈值滞回判定——上一时刻如果已经是预警状态，只需降到较低的保持阈值就继续维持；如果还没触发预警，需要超过较高的开启阈值才触发。两阈值差 0.05。

### Q7: 过平滑是什么意思

就是平滑门太保守了。smooth_gate 接近 1，意味着每次更新几乎全保留旧特征、几乎不接收新信息。后果是模型变得迟钝——晚高峰来了也不反应，真实的事故信号被过滤掉了。你的设计通过可训练参数避免了这个问题——logit 和 scale 是学出来的，不是写死的。

### Q8: ConvLSTM 是干什么的

位置在模型最后一步：动态特征和静态特征拼接后进入 ConvLSTM2D（1×1 卷积核），做最后一轮时空联合编码。2015 年香港科技大学 Shi 等人提出，原本用于降水预报——把 LSTM 门控公式中的全连接换成卷积，这样既保留了 LSTM 记忆历史的能力，又保留了输入的空间结构。

### Q9: 评价指标详解

- **Recall**：真正出事故的地方你抓住了几个。最重要——漏报代价高。
- **Accuracy**：总的猜对多少。会骗人——负样本多，全判安全也能 78%。
- **Precision**：你报警的时候几次是真的。跟 Recall 是跷跷板。
- **F1**：Precision 和 Recall 的综合分。不给偏科的人高分。
- **AUC-ROC**：排序能力。有水分——负样本分母太大。
- **AUC-PR**：只看正样本找得好不好。比 ROC 更可信。

### Q10: 消融实验和对比实验的区别

**对比实验**是你跟别人比——12 个模型跑同一套数据，看谁分高，证明你的方法更好。**消融实验**是你跟自己比——把模型里的零件一件一件拆掉，看拆了之后效果差多少，证明你加的零件真有用。你 P5 左边表是对比实验，右边表是消融实验。

### Q11: 为什么工作符合本科毕设要求

本科毕设不要求从零发明，核心是三个：理解现有方法（你复现了 Attention-LSTM）、有自己的改进（平滑门+后处理，有消融验证）、完成工程闭环（数据→模型→前端大屏）。你三条都满足。关键是论文里标清楚哪部分是复现的、哪部分是自己的。

### Q12: 为什么不算抄袭

你复现了基线方法，标明了出处，在此基础上加了改进，用消融实验证明改进有效。这是学术研究的标准范式。关键是论文里要引用原始方法的出处，分清边界。

### Q13: 模型对比的特点

- **Myplan**：Evolution+MultiAttention+平滑门+后处理，你的
- **LSTM**：纯时序模型，不管空间，Recall 0.79
- **ConvLSTM**：卷积+LSTM，你模型最后一层也是它
- **XGBoost/LightGBM/CatBoost**：树模型，不懂时空关系
- **ARIMA**：60 年老方法，只做单变量时序，Recall 0.29
- **SNIPER**：交通预测模型，Accuracy 高但 Recall 只有 0.27
